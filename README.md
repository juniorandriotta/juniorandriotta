## Sobre mim

Sou **Donizeti Andriotta Junior**, arquiteto de software e desenvolvedor full-stack. Construo produtos digitais de ponta a ponta, conectando arquitetura, desenvolvimento web e mobile e operação em produção.

Meu foco está em **desempenho, manutenção e previsibilidade de custos**, com decisões técnicas alinhadas às necessidades de cada produto.

- **Arquitetura:** plataformas SaaS multi-tenant, monólitos modulares e microserviços.
- **Web e mobile:** interfaces com Next.js e React Native, integradas a serviços em Node.js e TypeScript.
- **Infraestrutura:** pipelines de CI/CD, containers Docker e ambientes self-hosted com Traefik e Portainer.
- **Inteligência artificial:** integração de modelos locais para automatizar e otimizar fluxos corporativos.
